#+TITLE: Pathogen Configuration Framework
#+AUTHOR: Victor Santos
#+DESCRIPTION: A declarative, namespaced, and dependency-aware Emacs configuration engine.

Pathogen is a "biological" configuration framework for Emacs. Unlike traditional flat configs, Pathogen treats features as Germs that infect the host (Emacs) through a controlled Infection Vector.

* 🧬 Key Features

- Declarative Layers: Define your entire setup in a single list.
- Genetic Isolation: Automatic variable namespacing to prevent collisions.
- Dependency Sequencing: Germs resolve their own load order via topological sorting.
- Diagnostic Microscope: Visual tree representation of your configuration state.

* 🧪 Laboratory Structure  

Your =~/.emacs.d= should be organized as follows:

#+begin_src text
~/.emacs.d/
├── core/                  # The Pathogen Engine
│   ├── dna.el             # Class definitions & Registry
│   ├── sequence.el        # DAG Sorting & Propagation
│   └── incubator.el       # Variable injection & File loading
├── germs/                 # Your Configuration Modules (The Library)
│   ├── +ui/
│   │   └── fonts/
│   │       ├── genome.el   # Data/Variables blueprint
│   │       └── symptoms.el # Package configuration & UI
│   └── +emacs/
│       └── org/
└── init.el                # The Patient (Bootstrap)
#+end_src

* 💉 Usage

** 1. Define the Infection Vector

Pathogen looks for a configuration file via the =PATHOGEN_CONFIG_FILE= environment variable (defaults to =~/.pathogen.el=).

#+begin_src emacs-lisp
;; ~/.pathogen.el
(infect!
  +ui/themes
  (+ui/fonts :variables (list :default-height 190))
  +emacs/better-defaults
  (+productivity/gtd :deps '(+emacs/org)
                     :variables (list :inbox "~/org/inbox.org")))
#+end_src

** 2. Developing Germs

Use with-germ-data to access your injected variables safely without typing full namespaces.

#+begin_src elisp
;; germs/+ui/fonts/symptoms.el
(with-germ-data +ui/fonts (default-height)
  (set-face-attribute 'default nil :height default-height))  
#+end_src

* 🔬 Diagnostics

The framework provides built-in tools to monitor the health of the host.

- =M-x pathogen-microscope= :: Displays a visual dependency tree and the status of all registered Germs.
- Quarantine Alert :: If a Germ fails to load (due to syntax errors or missing paths), Pathogen isolates it and presents a biopsy report on startup.

* 🛡️ Scoping & Namespacing

Pathogen prevents "Global Pollution" by automatically prefixing variables. A variable passed as =:inbox= to the =+productivity/gtd= germ is internally stored as =+productivity/gtd-inbox=. This ensures that multiple germs can use common property names without conflict.

🕹️ Protocol Commands

| Command                    | Function                                          |
|----------------------------+---------------------------------------------------|
| infect!                    | Declaratively initialize the genome.              |
| pathogen-microscope        | View the dependency tree and germ status.         |
| pathogen-lab-generate-germ | Synthesize a new germ directory with boilerplate. |
| pathogen-lab-clear-genome  | Wipe the registry for a clean reload.             |

# README_1.org Content
* 🧬 Pathogen: Biological Configuration Engine

Pathogen is a Directed Acyclic Graph (DAG) based configuration manager for Emacs. Instead of linear loading, Pathogen treats features as Germs that infect the Host (Emacs) based on their genetic dependencies.

* 🏛 The Architecture (The Laboratory)

The core engine is divided into specialized modules that follow the lifecycle of a biological entity:

File,Module,Role
pathogen.el,Patient Zero,The entry point that triggers the system-wide propagation.
core/dna.el,The Blueprint,Defines the pathogen-germ class and the global Genome registry.
core/sequence.el,The Sequencer,Logic for topological sorting (DAG) to determine load order.
core/incubator.el,The Cultivator,Handles the physical loading of files and variable injection.
core/microscope.el,Diagnostics,"Provides a visual dashboard of active, dormant, and quarantined germs."
protocols/infection.el,The Vector,User-facing API and macros (define-germ) for configuration.
protocols/quarantine.el,Containment,Safety logic that isolates broken germs to prevent host failure.

* 🦠 Germ Anatomy (The Expression Order)

Every Germ is a directory containing up to three specific files. To ensure stability, Pathogen expresses these files in a strict chronological order:

-    genome.el (The Information): Custom variables and "pre-init" settings.
-   enzymes.el (The Catalysts): Custom functions, macros, and internal logic.
-   symptoms.el (The Expression): Package declarations (use-package), keybindings, and UI tweaks.

* 🚀 Operational Procedures
1. Synthesizing a New Germ

To create a new feature layer, use the automated synthesis tool: M-x pathogen-lab-generate-germ This creates the folder and the three-file structure automatically.
2. Defining Dependencies

In your init.el, define your germs. Pathogen will automatically calculate the correct order even if you define them out of sequence.

#+begin_src emacs-lisp
(define-germ 'completion-germ)

(define-germ 'python-germ 
  :deps '(completion-germ) 
  :vars '(:python-backend lsp))
#+end_src

3. Triggering Propagation

To start the infection process, call:
#+begin_src emacs-lisp
(pathogen-propagate)
#+end_src

🛡 Safety & Diagnostics
The Quarantine Protocol

If a Germ fails to load—or if its dependencies are missing—Pathogen moves it to Quarantine. This prevents Emacs from crashing and ensures that a single broken layer doesn't compromise the entire Host.
The Microscope

Use M-x pathogen-microscope to view the current state of the laboratory. It displays:

-   ACTIVE: Successfully expressed germs.
-   DORMANT: Germs disabled by the user.
-   QUARANTINED: Germs that failed to load due to errors or missing DNA.

#+begin_src emacs-lisp
;; To create a file, visit it with ‘C-x C-f’ and enter text in its buffer.

(require 'pathogen)

;; 1. Define how to find paths
(defun pathogen--find-germ-path (name)
  (expand-file-name (symbol-name name) "~/.emacs.d/germs/"))

;; 2. Define the 'hello' germ (matches directory name)
(define-germ hello :enabled t)

;; 3. Run the sequence
(pathogen-propagate)

;; 4. Verify using the 'hello' prefix
(if (boundp 'hello-germ-active-p)
    (message "Success! Variable check: %s" hello-germ-active-p)
  (message "Failure: Variable not found. Check *Messages* for Quarantine warnings."))

(let* ((germ-name 'hello)
       (expected-path (expand-file-name (symbol-name germ-name) "~/.emacs.d/germs/"))
       (germ-obj (pathogen-dna-get germ-name)))
  
  (message "--- PATHOGEN SANITY CHECK ---")
  
  ;; Check 1: DNA Registration
  (if (not germ-obj)
      (message "FAIL: Germ '%s' not found in DNA registry. Did you run (define-germ %s)?" germ-name germ-name)
    (message "PASS: Germ '%s' is registered." germ-name)
    
    ;; Check 2: Path Assignment
    (let ((stored-path (pathogen-germ-path germ-obj)))
      (if (string-empty-p stored-path)
          (message "FAIL: Germ object has no path! Check if pathogen-create-germ calls (pathogen--find-germ-path).")
        (message "PASS: Germ object path is: %s" stored-path)))
    
    ;; Check 3: Physical Directory
    (if (not (file-directory-p expected-path))
        (message "FAIL: Directory NOT found at %s" expected-path)
      (message "PASS: Directory exists.")
      
      ;; Check 4: File Presence
      (let ((files '("genome.el" "enzymes.el" "symptoms.el"))
            (found-any nil))
        (dolist (f files)
          (if (file-exists-p (expand-file-name f expected-path))
              (progn (message "  [+] Found: %s" f) (setq found-any t))
            (message "  [-] Missing: %s (Optional)" f)))
        (if (not found-any)
            (message "FAIL: No expression files found in directory! Check naming.")
          (message "PASS: Genetic material found."))))
    
    ;; Check 5: Status
    (message "CURRENT STATUS: %s" (if (pathogen-germ-loaded-p germ-obj) "ACTIVE" "INACTIVE")))
  
  (message "-----------------------------"))
#+end_src

#+begin_src emacs-lisp
(let* ((name 'hello)
       (germ (pathogen-dna-get name))
       (path (pathogen-germ-path germ))
       (sequence '("genome.el" "enzymes.el" "symptoms.el")))
  
  (message "--- BIOPSY START for %s ---" name)
  (message "1. Object found: %s" (if germ "YES" "NO"))
  (message "2. Target Directory: %s" path)
  (message "3. Directory exists: %s" (file-directory-p path))
  
  (dolist (file sequence)
    (let ((full-path (expand-file-name file path)))
      (message "   Checking %s... %s" 
               file 
               (if (file-exists-p full-path) "FOUND" "MISSING"))))
  (message "--- BIOPSY END ---"))

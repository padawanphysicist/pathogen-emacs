* Introduction

I have been using Emacs continuously since 2010 and I really like the idea of starter kits. I've used distributions like [[https://www.spacemacs.org/][Spacemacs]] and [[https://github.com/hlissner/doom-emacs][Doom Emacs]] until I concluded that they usually make a lot assumptions that are not fit for what I need.

Of course you can try to fork some of those kits in the wild and try to trim the pieces you don't want, but I found this to be too time consuming. So I decided to rewrite my own configuration as a starter-kit, to slowly organize the code I have and maybe make it useful for someone else besides me.

Since I started working on this during the social distancing measures taken after COVID-19 world pandemic I decided to call it =Pathogen=.

The philosophy is to be:
- Stable :: Prefer built-in features and well-established packages
- Simple :: Clear, straightforward configuration without magic
- Easy to understand :: Comprehensive documentation and comments

This means that by default it won't have all the fanciness of Spacemacs or Doom. Unless you are willing to accept a huge amount of code/packages without understanding them well (which makes you pass through hell when something goes astray), as an Emacs user you're going to have to get minimally comfortable seeking out new pieces of elisp code, bringing them in and configuring them. The Starter Kit should serve mainly as a guidance in this process by giving hints as to where to start and what to look for.

* Requirements

- [[https://www.gnu.org/software/emacs/][GNU Emacs]] 27.1 or higher
- [[https://git-scm.com/][Git]]
- *Internet connection* for initial package installation

* Installation
** Quick Start

1. Backup your existing Emacs configuration (if applicable):
   #+begin_src bash
   [ -d ~/.emacs.d ] && mv ~/.emacs.d ~/.emacs.d.backup
   [ -f ~/.emacs ] && mv ~/.emacs ~/.emacs.backup
   #+end_src

2. Clone this repository:
   #+begin_src bash
   git clone https://codeberg.org/padawanphysicist/pathogen-emacs.git ~/.emacs.d
   #+end_src

3. Launch Emacs:
   #+begin_src bash
   emacs
   #+end_src

** Updating

To update Pathogen to the latest version:
#+begin_src bash
cd ~/.emacs.d
git pull
#+end_src

* Customization

** Personal Configuration File

For personal tweaks without modifying the core repository, create a =~/.pathogen.el= file:
#+begin_src emacs-lisp
;;; ~/.pathogen.el --- Personal Emacs configuration

;; Example: Override theme
(load-theme 'doom-gruvbox t)

;; Example: Personal keybindings
(global-set-key (kbd "C-c l") 'org-store-link)
#+end_src

This file is loaded *after* all Pathogen modules, allowing you to easily override any default behavior.

#+title: Pathogen Emacs Configuration Documentation

* Introduction

This document provides an overview of the "Pathogen" Emacs configuration framework. This setup is designed to be modular, extensible, and easy to maintain through a system of "layers". It uses `elpaca` for package management and `use-package` for declarative package configuration.

* Core Concepts

The configuration is built on two main ideas:

1.  *Layers*: A layer is a self-contained unit of configuration that groups together related packages, settings, and functions for a specific purpose (e.g., a programming language, a tool, or a theme).
2.  *Declarative Configuration*: Packages are configured using the `use-package` macro, which allows for clean, organized, and lazy-loaded setups.

* File & Directory Structure

The project has a specific structure to keep the configuration organized:

- =early-init.el=: Loaded before Emacs is fully initialized. Used for performance tweaks and disabling UI elements early to prevent flickering.
- =init.el=: The main entry point. It loads the core system, registers layer directories, and loads the user-defined layers.
- =core/=
  - =package-manager.el=: Bootstraps and configures the `elpaca` package manager.
  - =layers.el=: Contains the core logic for the layer system.
  - =variables.el=: Defines global variables for the framework.
- =layers/=: The default directory where all configuration layers are stored.
- =doc/=: Contains documentation files, like this one.

* The Layer System

A layer is a directory containing files that configure a specific piece of functionality.

**Layer Structure**

A layer directory must be placed in one of the registered `pathogen-layers-dirs`. Inside, it can contain the following files, which are loaded in order:

1.  =variables.el=: Declare all configurable variables using =defvar= or =defcustom=. This allows users to override settings without modifying the layer's code.
2.  =functions.el=: Define any helper functions or internal utilities needed by the layer.
3.  =config.el=: The main configuration file. Use =use-package= here to install and configure packages, set keybindings, and define mode hooks.

**Loading Layers**

Layers are loaded in your personal configuration file (e.g., =~/.pathogen.el=) by adding them to the =pathogen-configuration-layers= list. The recommended way to do this is with the =pathogen-layers!= macro.

#+BEGIN_SRC emacs-lisp
;; In your personal config file
(pathogen-layers!
  ;; A simple layer
  base

  ;; A layer from a subdirectory (e.g., layers/+emacs/base)
  +emacs/base

  ;; A layer with variables
  (+lang/python :variables (:backend lsp :formatter black))
  )
#+END_SRC

**Passing Variables to Layers**

You can customize a layer by passing variables to it directly in the =pathogen-layers!= macro. The key-value pairs are converted into layer-specific variables.

For example, =(:backend lsp)= in the =+lang/python= layer will set a variable named =pathogen-lang-python/backend= to ='lsp=. The layer's =config.el= can then use this variable to change its behavior.

* Package Management

**Adding a Package**

To add a new package, find the appropriate layer (or create a new one) and add a =use-package= declaration to its =config.el= file.

#+BEGIN_SRC emacs-lisp
;; In layers/+tools/git/config.el
(use-package magit
  :bind ("C-x g" . magit-status))
#+END_SRC

`elpaca` will automatically detect and install the package on the next startup.

**Overriding Package Recipes**

If you need to use a specific fork, branch, or commit of a package, you can provide an `:elpaca` recipe.

#+BEGIN_SRC emacs-lisp
;; Use a forked repository
(use-package projectile
  :elpaca (projectile :host github :repo "your-username/projectile"))

;; Use the "develop" branch
(use-package org-mode
  :elpaca (org-mode :branch "develop"))
#+END_SRC

* Creating a New Layer

1.  *Create the Directory*: Create a new directory in =layers/=. For example, =layers/+tools/my-tool=.
2.  *Add Configuration*: Create a =config.el= file inside the new directory.
3.  *Add Packages*: Add =use-package= declarations to =config.el= for the packages you need.
4.  *(Optional) Add Variables*: If the layer needs to be configurable, create a =variables.el= file and declare the variables.
5.  *Enable the Layer*: Add the new layer to the =pathogen-layers!= list in your personal configuration file.

    #+BEGIN_SRC emacs-lisp
    (pathogen-layers!
      base
      ;; ... other layers
      +tools/my-tool)
    #+END_SRC
6.  *Restart Emacs*: The new layer and its packages will be loaded.
